# Blop Privacy Policy (summary)

Last updated: 2026-07-27

Blop is a local-first notes app. Your notes stay on your device unless you
explicitly use optional cloud features (Blop Study share/login).

## Crash reports (optional)

If you enable **crash upload** in Settings → App → Erweitert (or accept the
first-run prompt), Blop may send technical crash diagnostics to our crash
backend (Sentry) so we can fix stability issues. Crash reports can include
stack traces, app/OS version, and device class — not your note contents.

You can turn crash upload off at any time. Existing consent is stored only
on this device (`privacy/crash_upload_consent` in app settings).

## Local diagnostics

Even with crash upload off, Blop may keep a short local crash log on disk so
you can copy it from the in-app crash overlay. That log never leaves the
device unless you share it yourself.

## Account / Study

Signing in to Blop Study is optional. Notes work offline without Study.
Share and cloud sync only run when you choose those actions while signed in.

## Contact

Questions about privacy: use the project repository or the contact channel
published with your Blop build / store listing.
